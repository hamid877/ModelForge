# ModelForge

ModelForge is an end-to-end machine learning platform for
training, tracking, serving, and deploying machine learning models.

## Goals

- Data preprocessing
- Machine learning model training
- Model evaluation
- REST API serving
- Experiment tracking
- Containerization
- CI/CD
- Cloud deployment
- Monitoring

## Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- FastAPI
- Docker
- GitHub Actions
- AWS
- MLflow
- Prometheus
- Grafana
